Danil AI 1.0

Краткое описание
Danil AI 1.0 - простая первая версия десктопного AI-ассистента на Python и PyQt6. Приложение открывает одно окно чата, принимает сообщение пользователя и отправляет историю переписки в локальную модель Ollama.

Файлы версии
- danilAi.py - исходный код версии 1.0.
- danilai.exe - собранный exe-файл версии 1.0.
- README.txt - описание версии.
- СхемаПрограммы.drawio - редактируемая черно-белая диаграмма draw.io.
- Пользователь.png - блок схема программы со стороны пользователя
- Внутреняя.png - блок схема программы

Требования для запуска исходника
- Python 3.8 или новее.
- PyQt6.
- requests.
- Ollama с моделью llama2 для получения реальных ответов.

Установка зависимостей
pip install PyQt6 requests

Запуск
python danilAi.py

Или запустить готовый файл:
danilai.exe

Интерфейс
- Заголовок Danil AI 1.0.
- Область сообщений.
- Поле ввода текста.
- Кнопка Отправить.
- Кнопка Очистить чат.
- Строка состояния.

Горячая клавиша
- Ctrl+Enter - отправить сообщение.

Как работает программа
1. Запускается QApplication.
2. Создается главное окно DanilAssistant.
3. В окне создаются область сообщений, поле ввода и кнопки.
4. Пользователь вводит сообщение.
5. Сообщение добавляется на экран и в список messages.
6. ResponseWorker запускается в отдельном потоке.
7. Поток отправляет POST-запрос в Ollama: http://localhost:11434/api/chat.
8. Ответ модели возвращается в главное окно через сигнал response_ready.
9. Программа показывает ответ в чате и снова включает кнопку отправки.

Ограничения версии 1.0
- Нет базы данных.
- История не сохраняется после закрытия программы.
- Нет нескольких диалогов.
- Нет настроек API-ключа.
- Используется только локальная модель Ollama llama2.

Отличие от версии 2.0
Версия 1.0 показывает базовую идею ассистента: окно чата, отправка сообщения и получение ответа. Версия 2.0 расширяет эту основу: добавляет SQLite, список диалогов, настройки API-ключа и выбор режима ответа.
