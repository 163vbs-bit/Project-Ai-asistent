Danil AI 2.0

Краткое описание
Danil AI 2.0 - расширенная версия десктопного AI-ассистента на Python и PyQt6. В отличие от версии 1.0, здесь есть несколько диалогов, сохранение истории в SQLite, окно настроек и два варианта генерации ответа: локальная модель Ollama или OpenAI API.

Файлы версии
- danilAi.py - исходный код версии 2.0.
- danilai.exe - собранный exe-файл версии 2.0.
- README.txt - описание версии.
- СхемаПрограммы.drawio - редактируемая черно-белая диаграмма draw.io.
- Пользователь2.png - блок схема программы со стороны пользователя
- Внутерняя2.png - блок схема программы

Требования для запуска исходника
- Python 3.8 или новее.
- PyQt6.
- requests.
- SQLite используется через стандартный модуль sqlite3.

Установка зависимостей
pip install PyQt6 requests

Запуск
python danilAi.py

Или запустить готовый файл:
danilai.exe

Интерфейс
- Левая панель со списком диалогов.
- Кнопка Новый диалог.
- Кнопка Удалить диалог.
- Кнопка Настройки.
- Верхняя панель с выбором модели и кнопкой очистки.
- Область сообщений.
- Поле ввода и кнопка Отправить.

Горячие клавиши
- Ctrl+Enter - отправить сообщение.
- Ctrl+N - создать новый диалог.

База данных
Программа создает файл chat_history.db рядом с приложением. В базе есть три таблицы:
- conversations - список диалогов.
- messages - сообщения пользователя и ассистента.
- settings - сохраненные настройки, например API-ключ.

Как работает программа
1. Запускается QApplication.
2. Создается главное окно AIAssistant.
3. ChatDatabase создает таблицы SQLite, если их еще нет.
4. AIEngine отвечает за выбор источника ответа.
5. Интерфейс загружает список диалогов из базы.
6. Если диалогов нет, создается новый.
7. Пользователь вводит сообщение.
8. Сообщение показывается в интерфейсе и сохраняется в SQLite.
9. В отдельном потоке вызывается generate_response.
10. Если указан валидный API-ключ, запрос идет в OpenAI API.
11. Если ключа нет, запрос идет в локальную Ollama.
12. Ответ показывается в чате и сохраняется в базу.

Отличие от версии 1.0
- Код разделен на классы ChatDatabase, AIEngine, AIAssistant и SettingsDialog.
- Есть постоянное хранение истории.
- Можно создавать, переключать, очищать и удалять диалоги.
- Есть настройки API-ключа.
- Есть режим OpenAI API и локальный режим Ollama.
- Интерфейс крупнее и содержит боковую панель.

Важное замечание
Для локального режима должна быть запущена Ollama с моделью llama2. Для OpenAI-режима нужен действующий API-ключ и интернет.
